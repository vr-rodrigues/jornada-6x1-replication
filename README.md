# Replication Package — *How much productivity do we need to reduce the workweek?*

Replication code, data, and outputs for the paper:

> Rangel, V. (2026). *How much productivity do we need to reduce the workweek? A structural analysis of Brazil's PEC 8/2025.*

The paper builds a static partial-equilibrium model with a CES aggregator over formal and informal effective labor, calibrated to Brazilian microdata, and computes the one-off TFP gain $A_{\text{req}}$ that would offset the short-run output cost of cutting the statutory workweek from 44 to 36 hours.

The headline result is $A_{\text{req}} \approx 6.6\%$ under the preferred specification, with a conservative upper bound a couple of percentage points higher.

## Reproducing the paper

### Requirements

- **Python 3.10+** with `numpy`, `pandas`, `matplotlib`, `scipy`, `requests` (see `requirements.txt`)
- **R 4.0+** (only for the sectoral PNAD microdata pipeline) with `PNADcIBGE`, `survey`, `dplyr`, `ggplot2`
- A working internet connection on first run (PNAD microdata is downloaded from the IBGE API; PWT 10.01 ships with the package)
- LaTeX (TinyTeX, TeX Live, or MiKTeX) to recompile the paper from source

### Quick start

```bash
git clone https://github.com/vr-rodrigues/jornada-6x1-replication.git
cd jornada-6x1-replication
pip install -r requirements.txt
python run_all.py
```

`run_all.py` runs calibration → model → tables/figures → unit tests in sequence and writes outputs to `output/`. Expected runtime on a modern laptop is under five minutes (the PNAD download is the slowest step).

### Step-by-step

```bash
# 1. Calibrate (moment matching, sigma_sub, kappa, psi, tau, pi_m)
python src/calibration/calibrate_all.py

# 2. Regenerate every numbered table and figure
python src/tables_figures/compute_tfp_anchor.py
python src/tables_figures/compute_stress_test.py
python src/tables_figures/plot_main_figures.py
python src/tables_figures/plot_welfare_schedule.py
python src/tables_figures/compute_portugal_validation.py

# 3. Run unit tests
python -m unittest tests.test_model -v

# 4. Compile the paper (optional)
cd paper/tex && pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

### Sectoral extension (optional, requires R)

```bash
# Downloads PNAD Continua microdata from IBGE API
Rscript src/sectoral/data/pnad_sectoral_microdata.R
Rscript src/sectoral/figures/plot_sectoral_figures.R
```

The R scripts resolve paths relative to the repository root using the environment variable `JORNADA_BASE_DIR`. Set it to the repository root before running, e.g. `export JORNADA_BASE_DIR=$(pwd)`. If unset, the scripts fall back to the current working directory.

## Data

| Folder | Source | Redistribution |
|---|---|---|
| `data_raw/pwt1001.xlsx` | Penn World Table 10.01, Feenstra-Inklaar-Timmer (2015) | Public, included |
| `data_intermediate/` | Aggregated PNAD/DIEESE/NR-17 stats | Aggregates only — no individual records |
| `data_final/` | Calibration targets and parameter tables | Derived; included |

**Restricted microdata** (PNAD individual records, RAIS) are **never stored** in this repository. They are downloaded directly from the IBGE API by the sectoral R pipeline, and only aggregated targets are persisted. See `docs/DATA_PROVENANCE.md` for hashes, URLs, and collection dates.

## Tests

`tests/test_model.py` covers six invariants of the model:

1. Baseline reproduces calibration targets (κ, η_I, baseline FOC).
2. $A_{\text{req}}$ is monotone in the cap.
3. Sensitivity to σ_sub.
4. Hours-bin distribution θ sums to 1.
5. Welfare object: GHH composite utility and CV calculation.
6. Small-vs-large firm heterogeneity.

Run with `python -m unittest tests.test_model -v`.
