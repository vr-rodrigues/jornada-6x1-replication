# Replication Package -- How much productivity do we need to reduce the workweek?

This directory is the self-contained replication package for:

> Rangel, V. (2026). *How much productivity do we need to reduce the workweek? A structural analysis of Brazil's PEC 8/2025.*

The package regenerates the calibration results, validation JSON files, paper tables, paper figures, and final LaTeX PDFs from the files included here. The master command is `run_all.py`; it also copies generated figures/tables into `paper/tex/` so the manuscript can be compiled directly from the package.

## Quick Start

On Windows:

```powershell
py -m pip install -r requirements.txt
py run_all.py --tests --paper
```

On macOS/Linux:

```bash
python -m pip install -r requirements.txt
python run_all.py --tests --paper
```

Successful completion leaves:

- generated numerical outputs in `output/`
- generated LaTeX tables in `output/tables/`
- generated paper figures in `output/figures/`
- synced manuscript assets in `paper/tex/figures/` and `paper/tex/*_autogen.tex`
- compiled PDFs in `paper/`

If LaTeX or a Python script fails, `run_all.py` exits nonzero. Build errors are not masked.

## What `run_all.py` Does

`run_all.py` runs the referee-facing pipeline in this order:

1. baseline calibration and preferred flat-below calibration
2. conservative and preferred joint-envelope validation grids
3. historical TFP table and figure
4. stress-test table
5. main figures, including the generated output decomposition JSON
6. welfare schedule and welfare-threshold figure
7. Portugal validation table
8. appendix envelope table generated from validation JSON
9. sectoral figure from included sectoral results
10. paper asset sync into `paper/tex/`
11. optional unit tests with `--tests`
12. optional LaTeX compilation with `--paper`

The asset sync is deliberate: the LaTeX sources search `paper/tex/figures/`, while the code writes to `output/figures/`. The orchestrator now bridges those locations and checks that every referenced figure/table exists before compiling.

## Requirements

- Python 3.10+
- Python packages in `requirements.txt`
- LaTeX distribution with `pdflatex` and `bibtex` for `--paper`
- R 4.0+ only for optional PNAD microdata sectoral rebuilding

The current package includes the aggregate data needed for the default pipeline. Restricted individual-level PNAD or RAIS microdata are not stored in this repository.

## Optional Sectoral Microdata Rebuild

The default pipeline uses included sectoral outputs. To rebuild the sectoral PNAD inputs from microdata, run the R scripts under `src/sectoral/` after installing the R dependencies documented there. Those scripts download public PNAD Continua data and persist only aggregates.
